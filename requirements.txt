# Requirements der Lo-Fi-Pipeline (Audio + Video, gemeinsames .venv)
#
# Erzeugt per `pip freeze` aus dem tatsaechlich laufenden Trainings- und Generierungs-
# Environment. Enthaelt beide Pipelines: Audio (MusicGen/LoRA - audiocraft, transformers,
# xformers, librosa, demucs) und Video (LTX-Video-Trainer - diffusers, decord, opencv).
#
# WICHTIG - zweite Umgebung fuer die NIQE-Bewertung:
#   Die quantitative Videobewertung (NIQE) laeuft NICHT in diesem venv, sondern in einer
#   getrennten Umgebung, siehe requirements-niqe.txt. Grund: pyiqa erzwingt transformers>=5,
#   waehrend diese Pipeline transformers==4.52.2 benoetigt. Wird pyiqa in dieses venv
#   installiert, starten diffusers und ltxv_trainer nicht mehr.
#
# Nicht durch diese Datei abgedeckt (siehe NACHBAUANLEITUNG.md):
#   - Python 3.11 (getestet: 3.11.0rc1) - 3.12 bricht bei audiocraft
#   - NVIDIA-GPU + Treiber (getestet: RTX A6000, Treiber 580.173.02); die CUDA-Runtime kommt
#     ueber die nvidia-cu*-Pakete unten mit, ein separates CUDA-Toolkit ist nicht noetig
#   - ffmpeg als System-Paket (getestet: 4.4.2, Ubuntu 22.04)
#   - Node.js 22.x + npm fuer das Frontend unter frontend/ (eigene package.json dort)
#   - Modellgewichte: facebook/musicgen-melody-large und LTXV_13B_097_DEV werden beim
#     ersten Lauf geladen; der LoRA-Adapter liegt als GitHub-Release (lora-adapter-v1)
#
# Installation:
#   python3.11 -m venv .venv
#   .venv/bin/pip install --extra-index-url https://download.pytorch.org/whl/cu124 -r requirements.txt
#
# Das --extra-index-url ist noetig, weil torch/torchaudio als +cu124-Build referenziert sind
# (auf PyPI liegen nur die CPU-Varianten).
