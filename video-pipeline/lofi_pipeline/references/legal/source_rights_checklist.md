# Source Rights Checklist

## Purpose

This document tracks the legal/usage status of all reference material used in the
Lo-Fi video pipeline. The pipeline extracts only abstract motion principles and style
descriptions from reference videos — it does NOT copy, redistribute, or embed any frames
or audio from these sources.

## Usage Policy for this Project

- Reference videos are watched and analyzed manually
- No frames are embedded in the model or training data from these sources (unless
  the source explicitly allows it under Creative Commons or similar)
- Motion profiles (YAML files) describe abstract timing and motion principles only
- Generated AI outputs are original creative work, not derivative works of the references
- Training data (bamboo, cabin clips) uses YouTube content under fair-use assumption
  for academic/research purposes — this should be verified before commercial use

## Academic Use Note

This project is a Bachelor's thesis (Bachelorarbeit) at a German university. Use of
copyrighted video material for analysis is generally covered under §51 UrhG (citation
right) and §60a–60c UrhG (use for education and research). Generated outputs are original
AI-generated content. Consult your university's guidelines if submitting generated
video as part of the thesis deliverables.
