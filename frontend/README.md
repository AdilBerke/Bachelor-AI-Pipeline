# Lo-Fi Synth Studio

Erstelle eine professionelle, moderne und visuell hochwertige Website für eine Bachelorarbeit mit dem Titel:

„Entwicklung und Bewertung einer automatisierten Pipeline zur KI-gestützten Generierung von Lo-Fi-Musik“

Die Website soll das gesamte Bachelorprojekt verständlich und technisch glaubwürdig präsentieren. Sie soll wie eine hochwertige Forschungs- und Projektwebsite wirken, nicht wie eine gewöhnliche Musik-Streaming-Seite und nicht wie eine typische KI-Landingpage.

Ziel der Website

Die Website präsentiert eine automatisierte KI-Pipeline, die:

Lo-Fi-bezogene Inhalte und Metadaten erfasst

Audiodaten verarbeitet und analysiert

Trainingsdaten erzeugt

ein generatives Deep-Learning-Modell anpasst und trainiert

neue Lo-Fi-Musik generiert

ergänzend kurze GIFs beziehungsweise visuelle Inhalte erzeugt

die Ergebnisse automatisch bewertet

die generierte Musik mit einer Baseline vergleicht

über ein webbasiertes Frontend und Backend nutzbar gemacht wird

Der Schwerpunkt von Adil Berke Savcili liegt auf der MP3-Musikerstellung, der Audioverarbeitung, dem Modelltraining und der Musikgenerierung. Die Videogenerierung wird schwerpunktmäßig von Inan Deniz Arduc bearbeitet. Die gemeinsame Pipeline verbindet beide Bereiche.

Farbwelt

Hintergrund: sehr dunkles Anthrazit oder tiefes Schwarzgrau

Flächen: leicht hellere Grautöne

Text: gebrochenes Weiß

Sekundärtext: kühles Grau

Akzentfarbe: warmes Orange, gedämpftes Violett oder dezentes Blau

Akzentfarben sparsam einsetzen

Keine starken Farbverläufe über die gesamte Seite. Verläufe nur dezent für Licht, Tiefe oder einzelne Hervorhebungen verwenden.

Typografie

Verwende eine moderne, klare Sans-Serif-Schrift.

Technische Begriffe, Modellinformationen, Messwerte oder Statusanzeigen dürfen teilweise in einer Monospace-Schrift dargestellt werden.

01 Datenerfassung
02 Audio- und Metadatenverarbeitung

Trainingsdaten

7. Evaluation und Baseline-Vergleich

Erstelle einen klaren Evaluationsbereich.

Überschrift:

Wie nah liegt die generierte Musik am Lo-Fi-Standard?

Die generierten Audios werden anhand verschiedener Scorer bewertet und mit einer Baseline beziehungsweise einem Genre-Standard verglichen.

Zeige eine übersichtliche Grafik mit genau zwei Linien:

Baseline beziehungsweise Genre-Standard

generierte Audioausgabe des Modells

Die Grafik soll nur die vergebenen Scorer-Punkte vergleichen.

Mögliche Achsen beziehungsweise Bewertungskategorien:

Lautheit

Bassanteil

Dynamik

Klangfarbe

Rauschanteil

Rhythmische Stabilität

Lo-Fi-Stiltreue

Loop-Qualität

Keine komplexen Audiospektren an dieser Stelle. Der Nutzer soll sofort sehen können, in welchen Kategorien das Modell besser oder schlechter als die Baseline abschneidet.

Nutze daneben kompakte Score-Karten:

Gesamtbewertung

höchste Übereinstimmung

größte Abweichung

Baseline-Differenz

Verwende nur Beispielwerte und kennzeichne sie deutlich als Demo-Daten.
