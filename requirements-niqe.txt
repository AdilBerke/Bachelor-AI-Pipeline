# Zusatzpakete fuer die NIQE-Bildqualitaetsbewertung
#
# WARUM EINE ZWEITE UMGEBUNG:
#   pyiqa erzwingt transformers>=5, die Pipeline in requirements.txt benoetigt dagegen
#   transformers==4.52.2. Beides zusammen in einem venv fuehrt dazu, dass diffusers und
#   ltxv_trainer nicht mehr starten. Die NIQE-Bewertung laeuft deshalb in einer eigenen
#   Umgebung und wird per Subprozess aufgerufen
#   (video-pipeline/lofi_pipeline/scripts/_niqe_worker.py).
#
# WICHTIG - diese Umgebung baut auf der Haupt-Umgebung auf:
#   Das venv wird mit --system-site-packages vom Interpreter der Haupt-Umgebung erzeugt.
#   Dadurch werden torch, torchvision, numpy, scipy und die uebrigen bereits in
#   requirements.txt gepinnten Pakete uebernommen, statt mehrere Gigabyte doppelt
#   abzulegen. Diese Datei enthaelt nur die Pakete, die zusaetzlich installiert werden
#   und die Haupt-Umgebung gezielt ueberlagern (insbesondere transformers).
#
# Installation (nach Schritt 3a, aus der Repo-Wurzel):
#   .venv/bin/python -m venv --system-site-packages .venv-niqe
#   .venv-niqe/bin/pip install -r requirements-niqe.txt
#
# Wofuer NIQE verwendet wird:
#   Naturalness Image Quality Evaluator, No-Reference-Metrik nach Mittal et al. (2013).
#   Bewertet die Einzelbildqualitaet der erzeugten Rohvideos; niedrigere Werte sind besser.
#   Ausgewertet werden zwoelf gleichmaessig verteilte Frames je Video in Originalaufloesung.
